# SylphxAI awesome-mcp-servers Fork

This repository is a SylphxAI fork of an MCP ecosystem directory. Its local
role is category intelligence and discovery for the SylphxAI MCP family.

## Lifecycle

- State: `adoption`
- Layer: `market-intelligence`

## Goals

- Maintain an ecosystem map that helps product repos understand MCP category
  shape, install expectations, capability gaps, and discovery patterns.
- Keep SylphxAI product claims in the owning product repositories.
- Use generated or validated metadata for any future scorecards or category
  snapshots.

## Non-Goals

- This repository does not own MCP product contracts, package release state,
  tool schemas, benchmarks, or commercial decisions for product repos.
- This repository does not replace upstream contribution policy.
- This repository does not become a manually maintained product-status registry.
